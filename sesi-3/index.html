Langkah Push ke GitHub
  1. Buka Terminal / Command Prompt di folder projek.
  2. Inisialisasi Git repository: git init
  3. Tambahkan berkas ini: git add index.html
  4. Lakukan Commit: git commit -m "Tugas 1-4 Bootstrap Portfolio"
  5. Hubungkan ke Repository GitHub Anda: git remote add origin https://github.com/USERNAME/REPOSITORY.git
  6. Unggah berkas: git push -u origin main
